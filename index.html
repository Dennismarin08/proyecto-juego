Cómo ejecutar el proyecto

1. Ejecutar desde navegador

Abre el juego con HTTP desde tu servidor local: http://localhost/JUEGO/index.html.

2. Iniciar backend Java

En la carpeta backend, ejecuta con Maven:

mvn compile exec:java

3. Guardado de progreso

El progreso se guarda en Java y aparece el botón Continuar partida cuando hay un avance.

Este proyecto usa Java y SQL para guardar el progreso. El juego solo funciona al 100% cuando el backend Java está en ejecución junto a las páginas servidas por el servidor local.
